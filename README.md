## Selected work

### [Streakwise](https://github.com/Hammad-Sheikhh/streakwise)

Time and progress tracker for people running several courses, projects and goals in parallel, with reports, share links and a per-account Claude connector. Released as v1.0.1.

`TypeScript` `React` `Vite` `Tailwind` `Supabase` · [Live](https://streakwise-mu.vercel.app) · [Demo](https://streakwise-mu.vercel.app/demo)

Two-board ESP32 rover. One board drives and logs telemetry, the other captures camera images, and a Python ground station lets an AI model choose the next move within firmware safety limits.

`C++` `ESP32` `ESP32-CAM` `Python` `Supabase`
